# 🔬 MicroSight AI – Portable Microplastic Detection and Water Pollution Assessment System

## 📌 Project Overview
MicroSight AI is a portable, AI-powered system designed for the preliminary visual detection and assessment of suspected microplastic particles in water samples.

The system combines hardware-based image acquisition, computer vision, deep learning, and Big Data analytics to support faster and more accessible water pollution screening.

## 🎯 Objectives
- Capture magnified images of particles collected from water samples.
- Automate particle-like object detection and counting using YOLOv8.
- Improve image quality through OpenCV preprocessing.
- Store sample-wise detection results in structured CSV/JSON formats.
- Perform large-scale data analysis using Apache Spark and Scala.
- Generate meaningful analytical reports and visualizations.

## ⚙️ Technologies Used

**Hardware:**
- ESP32-CAM (OV2640)
- Microscope / Macro Lens
- LED Illumination
- Membrane Filtration Unit

**Software:**
- Python
- OpenCV
- YOLOv8
- Apache Spark
- Scala
- CSV / JSON

## 🔄 System Workflow
1. Water Sample Collection
2. Membrane Filtration
3. Image Acquisition using ESP32-CAM
4. Image Preprocessing using OpenCV
5. Particle Detection and Counting using YOLOv8
6. Detection Results Export to CSV/JSON
7. Data Cleaning and Processing using Spark + Scala
8. Statistical Analysis and Visualization

## 🌍 Expected Impact
- Supports preliminary water pollution screening.
- Reduces dependence on manual visual observation.
- Enables structured analysis of multiple water samples.
- Provides a foundation for scalable environmental monitoring.

## 🚀 Project Vision
To develop an affordable, portable, and intelligent screening solution that combines computer vision and Big Data analytics for environmental monitoring.

**Note:** The system provides preliminary visual screening of suspected microplastic particles. Chemical identification requires additional laboratory validation.
